# utils.getTerm

公历 `y` 年第 `n` 个节气落在当月的哪一天。

## 引入

```ts
import { utils } from "@sanguo-dev/calendar";
```

## 签名

```ts
utils.getTerm(y: number, n: number): number;
```

## 用法

```ts
utils.getTerm(2026, 3); // 4
```

## 参数

| 参数 | 类型     | 说明                         |
| ---- | -------- | ---------------------------- |
| `y`  | `number` | 公历年，1900-2100            |
| `n`  | `number` | 第几个节气，1-24，`1` 为小寒 |

## 返回值

`number`，该节气所在公历月的日期数字。节气按公历顺序排列，第 `n` 个节气对应的公历月份为 `Math.ceil(n / 2)`。

## 错误

| 异常         | 场景                              |
| ------------ | --------------------------------- |
| `RangeError` | 年份不在 1900-2100，`n` 不在 1-24 |
