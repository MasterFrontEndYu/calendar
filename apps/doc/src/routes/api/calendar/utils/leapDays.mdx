# utils.leapDays

农历 `y` 年闰月的天数。

## 引入

```ts
import { utils } from "@sanguo-dev/calendar";
```

## 签名

```ts
utils.leapDays(y: number): number;
```

## 用法

```ts
utils.leapDays(2020); // 29
utils.leapDays(2026); // 0
```

## 参数

| 参数 | 类型     | 说明              |
| ---- | -------- | ----------------- |
| `y`  | `number` | 农历年，1900-2100 |

## 返回值

`number`，闰月天数，29 或 30；没有闰月时返回 `0`。

## 错误

| 异常         | 场景                                |
| ------------ | ----------------------------------- |
| `RangeError` | `y` 不是整数，或不在 1900-2100 之间 |
