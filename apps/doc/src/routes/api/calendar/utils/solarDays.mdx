# utils.solarDays

公历某个月的天数，自动处理闰年。

## 引入

```ts
import { utils } from "@sanguo-dev/calendar";
```

## 签名

```ts
utils.solarDays(y: number, m: number): number;
```

## 用法

```ts
utils.solarDays(2026, 2); // 28
utils.solarDays(2024, 2); // 29
```

## 参数

| 参数 | 类型     | 说明           |
| ---- | -------- | -------------- |
| `y`  | `number` | 公历年，1-9999 |
| `m`  | `number` | 公历月，1-12   |

## 返回值

`number`，28-31。

## 错误

| 异常         | 场景                           |
| ------------ | ------------------------------ |
| `RangeError` | 年份不在 1-9999，月份不在 1-12 |
