# calendar.isHeaderVisible

判断头部当前是否可见。

## 引入

```ts
import { createCalendarUI } from "@sanguo-dev/calendar-ui";

const calendar = createCalendarUI(container);
```

## 签名

```ts
calendar.isHeaderVisible(): boolean;
```

## 用法

```ts
calendar.isHeaderVisible(); // true
```

## 参数

无。

## 返回值

`boolean`，头部节点的 `hidden` 为 `false` 时返回 `true`。
