# calendar.showHeader

显示头部。

## 引入

```ts
import { createCalendarUI } from "@sanguo-dev/calendar-ui";

const calendar = createCalendarUI(container);
```

## 签名

```ts
calendar.showHeader(): void;
```

## 用法

```ts
calendar.showHeader();
```

## 参数

无。

## 返回值

`void`。

## 说明

把头部节点的 `hidden` 置为 `false`。`header: false` 创建的实例也可以用它临时显示头部。
