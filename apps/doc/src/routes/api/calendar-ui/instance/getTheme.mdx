# calendar.getTheme

读取当前主题。

## 引入

```ts
import { createCalendarUI } from "@sanguo-dev/calendar-ui";

const calendar = createCalendarUI(container);
```

## 签名

```ts
calendar.getTheme(): CalendarTheme;
```

## 用法

```ts
calendar.getTheme(); // "auto"
```

## 参数

无。

## 返回值

`CalendarTheme`，取值为 `"light"` / `"dark"` / `"auto"`，默认 `"auto"`。
