# calendar.getMinDate

读取当前最小可选日期。

## 引入

```ts
import { createCalendarUI } from "@sanguo-dev/calendar-ui";

const calendar = createCalendarUI(container);
```

## 签名

```ts
calendar.getMinDate(): Date | null;
```

## 用法

```ts
calendar.getMinDate(); // Date 或 null
```

## 参数

无。

## 返回值

`Date | null`，未设置时为 `null`。返回的是日期副本。
