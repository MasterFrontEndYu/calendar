# calendar.toggleHeader

切换头部的显示状态。

## 引入

```ts
import { createCalendarUI } from "@sanguo-dev/calendar-ui";

const calendar = createCalendarUI(container);
```

## 签名

```ts
calendar.toggleHeader(): void;
```

## 用法

```ts
calendar.toggleHeader();
```

## 参数

无。

## 返回值

`void`。

## 说明

按头部当前的 `hidden` 取反。
