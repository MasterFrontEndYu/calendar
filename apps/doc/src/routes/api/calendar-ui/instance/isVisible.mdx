# calendar.isVisible

判断整个日历当前是否可见。

## 引入

```ts
import { createCalendarUI } from "@sanguo-dev/calendar-ui";

const calendar = createCalendarUI(container);
```

## 签名

```ts
calendar.isVisible(): boolean;
```

## 用法

```ts
calendar.isVisible(); // true
calendar.hide();
calendar.isVisible(); // false
```

## 参数

无。

## 返回值

`boolean`，根节点的 `hidden` 为 `false` 时返回 `true`。
