# calendar.clearRange

清空选择范围。

## 引入

```ts
import { createCalendarUI } from "@sanguo-dev/calendar-ui";

const calendar = createCalendarUI(container);
```

## 签名

```ts
calendar.clearRange(): void;
```

## 用法

```ts
calendar.clearRange();
```

## 参数

无。

## 返回值

`void`。

## 说明

起点与终点都置为 `null`，重绘并触发 `onRangeChange({ start: null, end: null })`。单选模式下选中日期不变，但回调仍会触发。
