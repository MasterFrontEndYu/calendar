# createCalendarLunar

创建带农历、节气、节日与调休标记的日历实例。接口与 `createCalendarUI` 一致，额外接受节假日配置。

## 引入

```ts
import { createCalendarLunar } from "@sanguo-dev/calendar-ui-lunar";
import "@sanguo-dev/calendar-ui/style.css";
```

## 签名

```ts
createCalendarLunar(
  container: HTMLElement,
  options?: LunarCalendarOptions,
): CalendarInstance;

interface LunarCalendarOptions extends CalendarOptions<LunarResult> {
  holidays?: HolidayConfig;
  replaceHolidays?: boolean;
}
```

## 用法

```ts
const instance = createCalendarLunar(container, {
  initialDate: "2026-10-01",
  holidays: {
    setFestival: { sFtv: { "0105": ["公司年会"] } },
    setRest: { 2026: { xiu: ["0105"], ban: ["0106"] } },
  },
  onSelect: (day) => {
    day.subtitle; // "国庆节"
    day.badge; // { text: "休", tone: "rest" }
    day.data?.lMonthCn; // "八月"
  },
});
```

## 参数

| 参数                      | 类型                           | 默认    | 说明                                                                                    |
| ------------------------- | ------------------------------ | ------- | --------------------------------------------------------------------------------------- |
| `container`               | `HTMLElement`                  | -       | 日历根节点会追加到这个容器末尾                                                          |
| `options`                 | `LunarCalendarOptions`         | `{}`    | `CalendarOptions<LunarResult>` 的全部字段，外加下列字段                                 |
| `options.holidays`        | `HolidayConfig`                | -       | 本实例使用的节日 / 调休配置，字段见 [HolidayConfig](/api/calendar/types/holiday-config) |
| `options.replaceHolidays` | `boolean`                      | `false` | 为 `true` 时忽略内置数据，只使用 `holidays`                                             |
| `options.adapter`         | `CalendarAdapter<LunarResult>` | -       | 自定义适配器；传入后不再自动创建农历适配器                                              |

## 返回值

[`CalendarInstance`](/api/calendar-ui/instance)，与 `createCalendarUI()` 完全相同。`day.data` 是完整的 [`LunarResult`](/api/calendar/types/lunar-result)。

## 说明

- `initialDate`、`minDate`、`maxDate`、`mode`、`months`、`theme`、`size`、`animation`、`renderHeader`、`onSelect` 等字段与 [CalendarOptions](/api/calendar-ui/CalendarOptions) 一致；
- 配置在创建时校验并固定，之后修改 `holidays` 对象不会影响实例；
- 同一份 `holidays` 对象 + 相同的 `replaceHolidays` 会共享转换器。

## 错误

| 异常         | 场景                                                                           |
| ------------ | ------------------------------------------------------------------------------ |
| `TypeError`  | `holidays` 结构、年份或字段类型不合法，其它配置字段非法                        |
| `RangeError` | 日期不存在、`minDate` 晚于 `maxDate`、`months` 不是 1 或 2、约束下没有可选日期 |
