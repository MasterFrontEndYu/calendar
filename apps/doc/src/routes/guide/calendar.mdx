# calendar 核心

`@sanguogege/calendar` 是零依赖的公历 / 农历换算库。

```bash
bun add @sanguogege/calendar
```

## 导入方式

2.x 只导出默认 converter，没有具名运行时导出：

```ts
import calendar from "@sanguogege/calendar";
```

默认 converter 包括：

| 成员              | 类型 | 作用                       |
| ----------------- | ---- | -------------------------- |
| `solarToLunar`    | 方法 | 公历转农历                 |
| `lunarToSolar`    | 方法 | 农历转公历                 |
| `setHolidays`     | 方法 | 注入全局节日 / 调休配置    |
| `resetHolidays`   | 方法 | 恢复内置配置               |
| `getHolidays`     | 方法 | 取当前配置的深拷贝         |
| `createConverter` | 方法 | 创建带独立配置的 converter |
| `utils`           | 对象 | 底层工具函数               |

类型（`LunarResult`、`HolidayConfig`、`CalendarConverter` 等）仍然可以具名导入：

```ts
import type { LunarResult, HolidayConfig } from "@sanguogege/calendar";
```

## solarToLunar

```ts
calendar.solarToLunar(); // 今天
calendar.solarToLunar(2026, 10, 1);
```

| 参数 | 类型     | 必填 | 说明              |
| ---- | -------- | ---- | ----------------- |
| `y`  | `number` | 否   | 公历年，1900-2100 |
| `m`  | `number` | 否   | 公历月，1-12      |
| `d`  | `number` | 否   | 公历日            |

规则：

- 三个参数要么全部不传（取今天），要么全部传入；
- 非法日期、越界日期一律抛 `RangeError`，不会自动进位，也不会静默回退到今天；
- 支持范围：`1900-01-31 ~ 2100-12-31`。

### 返回值 LunarResult

| 字段                        | 类型                | 说明                                        |
| --------------------------- | ------------------- | ------------------------------------------- |
| `xiu`                       | `boolean`           | 是否在 `rest.json` 的放假日列表；与周末无关 |
| `ban`                       | `boolean`           | 是否在 `rest.json` 的补班日列表             |
| `gljr`                      | `readonly string[]` | 公历节日，没有时是共享空数组                |
| `nljr`                      | `readonly string[]` | 农历节日，没有时是共享空数组                |
| `lYear` / `lMonth` / `lDay` | `number`            | 农历年 / 月 / 日                            |
| `isLeap`                    | `boolean`           | 是否闰月                                    |
| `lMonthCn` / `lDayCn`       | `string`            | 农历月 / 日中文，如 `"闰四月"`、`"廿一"`    |
| `animal`                    | `string`            | 生肖，以农历年为准                          |
| `cYear` / `cMonth` / `cDay` | `number`            | 公历年 / 月 / 日                            |
| `gzYear`                    | `string`            | 干支年，以**立春**为界                      |
| `gzYearLunar`               | `string`            | 干支年，以正月初一为界                      |
| `gzMonth` / `gzDay`         | `string`            | 干支月（以节气为界）/ 干支日                |
| `gzHour`                    | `string[]`          | 当天十二个时辰的干支                        |
| `isToday`                   | `boolean`           | 是否今天（本地时区）                        |
| `nWeek`                     | `number`            | 星期 1-7，周日为 7                          |
| `dayOfWeek`                 | `number`            | 星期 0-6，周日为 0                          |
| `ncWeek`                    | `string`            | 星期中文，如 `"星期日"`                     |
| `term`                      | `string \| null`    | 节气名，非节气日为 `null`                   |
| `astro`                     | `string`            | 星座，如 `"摩羯座"`                         |

示例：

```ts
const day = calendar.solarToLunar(2026, 10, 1);

day.lMonthCn; // "八月"
day.lDayCn; // "廿一"
day.gljr; // ["国庆节", ...]
day.xiu; // true
day.ban; // false
day.term; // 当天不是节气时为 null
day.gzYear; // 干支年
day.dayOfWeek; // 0-6
```

## lunarToSolar

```ts
calendar.lunarToSolar(2024, 1, 1); // 2024-02-10
calendar.lunarToSolar(2020, 4, 1, true); // 2020-05-23（闰四月）
```

| 参数          | 类型      | 必填 | 说明              |
| ------------- | --------- | ---- | ----------------- |
| `y`           | `number`  | 是   | 农历年，1900-2100 |
| `m`           | `number`  | 是   | 农历月，1-12      |
| `d`           | `number`  | 是   | 农历日，1-30      |
| `isLeapMonth` | `boolean` | 否   | 是否闰月          |

- 闰月不存在、农历日期不存在、换算结果超过 2100-12-31 都会抛 `RangeError`；
- 返回值同样是完整的 `LunarResult`，可以用 `cYear/cMonth/cDay` 取公历日期。

## 节日与调休

### HolidayConfig

```ts
interface HolidayConfig {
  setFestival?: {
    /** 公历节日，key 为 MMDD */
    sFtv?: Record<string, string[]>;
    /** 农历节日，key 为 MMDD */
    lFtv?: Record<string, string[]>;
  };
  setRest?: {
    [year: string]: {
      /** 放假日期，MMDD */
      xiu?: string[];
      /** 补班日期，MMDD */
      ban?: string[];
    };
  };
}
```

年份范围 1900-2100，`MMDD` 必须是四位。格式错误会立即抛 `TypeError`，错误信息带完整字段路径。

### setHolidays

```ts
calendar.setHolidays({
  setFestival: {
    sFtv: { "0419": ["项目上线日"] },
    lFtv: { "0101": ["春节"] },
  },
  setRest: {
    2027: { xiu: ["0101", "0102"], ban: ["0104"] },
  },
});
```

| 参数              | 类型            | 说明                                     |
| ----------------- | --------------- | ---------------------------------------- |
| `config`          | `HolidayConfig` | 要注入的数据                             |
| `options.replace` | `boolean`       | 为 `true` 时丢弃内置数据，只使用传入数据 |

- 默认与当前配置**合并去重**，不修改内置 JSON，也不修改入参对象；
- 重复调用会继续叠加；
- 失败时不会破坏已有配置。

### getHolidays / resetHolidays

```ts
const snapshot = calendar.getHolidays(); // 深拷贝
calendar.setHolidays(snapshot); // 可以再传回去
calendar.resetHolidays(); // 恢复内置数据
```

`getHolidays()` 返回的 `HolidaySnapshot` 结构完整，可以直接传给 `setHolidays()` 或 `createConverter()`。

### xiu / ban 的语义

`xiu` / `ban` **完全由配置决定，与周末无关**：

- 在 `xiu` 列表里：`day.xiu === true`；
- 在 `ban` 列表里：`day.ban === true`；
- 普通周末不会自动算作休息；需要判断周末请用 `day.dayOfWeek` 或 `day.nWeek`。

内置 2026 数据来自[国务院办公厅通知](https://www.gov.cn/zhengce/content/202511/content_7047090.htm)：

| 假期   | 放假        | 补班        |
| ------ | ----------- | ----------- |
| 元旦   | 1/1 - 1/3   | 1/4         |
| 春节   | 2/15 - 2/23 | 2/14、2/28  |
| 清明节 | 4/4 - 4/6   | -           |
| 劳动节 | 5/1 - 5/5   | 5/9         |
| 端午节 | 6/19 - 6/21 | -           |
| 中秋节 | 9/25 - 9/27 | -           |
| 国庆节 | 10/1 - 10/7 | 9/20、10/10 |

## createConverter

全局 `setHolidays()` 同一时刻只能有一套配置。需要多套配置并存时，用 `createConverter()`：

```ts
const mainland = calendar.createConverter({
  setRest: { 2027: { xiu: ["0101", "0102"], ban: ["0104"] } },
});
const hongKong = calendar.createConverter({
  setRest: { 2027: { xiu: ["0101"] } },
});

mainland.solarToLunar(2027, 1, 4).ban; // true
hongKong.solarToLunar(2027, 1, 4).ban; // false
```

| 参数              | 类型            | 说明                               |
| ----------------- | --------------- | ---------------------------------- |
| `config`          | `HolidayConfig` | 独立配置，默认以内置数据为基准合并 |
| `options.replace` | `boolean`       | 为 `true` 时只用传入数据           |

返回的 `CalendarConverter`：

| 成员                                  | 说明                          |
| ------------------------------------- | ----------------------------- |
| `solarToLunar(y?, m?, d?)`            | 使用该 converter 的配置换算   |
| `lunarToSolar(y, m, d, isLeapMonth?)` | 使用该 converter 的配置换算   |
| `getHolidays()`                       | 该 converter 当前配置的深拷贝 |

注意：

- converter 的配置在创建时固定，之后调用全局 `setHolidays()` / `resetHolidays()` 不影响它；
- converter 也不会影响全局配置；
- `createConverter()` 默认从**内置数据**开始，不会继承全局 `setHolidays()` 的自定义数据。需要复制全局现状时用 `calendar.createConverter(calendar.getHolidays(), { replace: true })`。

## 工具函数

```ts
calendar.utils.lYearDays(2026); // 农历年天数
calendar.utils.leapMonth(2026); // 闰几月，0 表示不闰
calendar.utils.leapDays(2026); // 闰月天数
calendar.utils.lMonthDays(2026, 3); // 农历某月天数
calendar.utils.toChinaMonth(3); // "三月"
calendar.utils.toChinaDay(21); // "廿一"
calendar.utils.toChinaNum(3); // "三"
calendar.utils.solarDays(2026, 2); // 28
calendar.utils.solarFirstWeek(2026, 4); // 3（周日为 0）
calendar.utils.nthWeekdayOfMonth(2026, 5, 0, 2); // 10
calendar.utils.toAstro(4, 19); // "白羊座"
calendar.utils.getAnimal(2026); // "马"
calendar.utils.getTerm(2026, 3); // 4
calendar.utils.getSolarTerm(0); // "小寒"
calendar.utils.toGanZhi(40); // "甲辰"
calendar.utils.toGanZhiYear(2024); // "甲辰"
calendar.utils.toHourGanZhi(40); // ["甲子", "乙丑", ...]
```

## 错误与限制

| 异常         | 场景                                                   |
| ------------ | ------------------------------------------------------ |
| `RangeError` | 日期越界、日期不存在、闰月不匹配、工具函数参数越界     |
| `TypeError`  | `setHolidays` / `createConverter` 配置结构或类型不合法 |

```ts
try {
  calendar.solarToLunar(2024, 2, 30);
} catch (error) {
  console.error(error.message); // [calendar] solarToLunar(day) 必须在 1-29 之间，收到 30
}
```
