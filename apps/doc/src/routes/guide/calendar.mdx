# calendar 核心

`@sanguogege/calendar` 是零依赖的公历 / 农历换算库。

```bash
bun add @sanguogege/calendar
```

## 导入方式

默认导出就是 `createCalendar` 函数：

```ts
import createCalendar, { utils } from "@sanguogege/calendar";
```

- `createCalendar(config?, options?)` 创建独立实例；
- 不传参数时使用内置数据；
- 没有全局 `setHolidays` / `resetHolidays`，也没有默认 `calendar` 对象；
- `utils` 是独立的具名导出。

类型可以具名导入：

```ts
import type { Calendar, LunarResult, HolidayConfig } from "@sanguogege/calendar";
```

## createCalendar

```ts
const calendar = createCalendar();
const custom = createCalendar({
  setRest: { 2027: { xiu: ["0101", "0102"], ban: ["0104"] } },
});
```

| 参数              | 类型            | 说明                                      |
| ----------------- | --------------- | ----------------------------------------- |
| `config`          | `HolidayConfig` | 节假日 / 调休配置，默认与内置数据合并     |
| `options.replace` | `boolean`       | 为 `true` 时丢弃内置数据，只使用 `config` |

```ts
const onlyCustom = createCalendar(
  { setFestival: { sFtv: { "0101": ["只此一个"] } } },
  { replace: true },
);
```

规则：

- 每次调用都是独立实例；
- 配置在创建时校验、深拷贝并冻结；
- 修改入参对象不会影响已创建的实例；
- 多个实例互不影响，适合 SSR、并发和多套配置；
- 配置错误立即抛 `TypeError`，错误信息带 `createCalendar.…` 字段路径。

## 实例方法

| 方法                                  | 说明                                          |
| ------------------------------------- | --------------------------------------------- |
| `solarToLunar(y?, m?, d?)`            | 公历转农历；不传参数返回今天                  |
| `lunarToSolar(y, m, d, isLeapMonth?)` | 农历转公历                                    |
| `getHolidays()`                       | 当前配置的深拷贝，可再传给 `createCalendar()` |

```ts
const calendar = createCalendar();

calendar.solarToLunar(); // 今天
calendar.solarToLunar(2026, 10, 1);

calendar.lunarToSolar(2024, 1, 1); // 2024-02-10
calendar.lunarToSolar(2020, 4, 1, true); // 2020-05-23（闰四月）

const snapshot = calendar.getHolidays();
const copy = createCalendar(snapshot);
```

### solarToLunar 参数

| 参数 | 类型     | 必填 | 说明              |
| ---- | -------- | ---- | ----------------- |
| `y`  | `number` | 否   | 公历年，1900-2100 |
| `m`  | `number` | 否   | 公历月，1-12      |
| `d`  | `number` | 否   | 公历日            |

三个参数要么全部不传（取今天），要么全部传入。非法日期、越界日期抛 `RangeError`，不会自动进位。

### lunarToSolar 参数

| 参数          | 类型      | 必填 | 说明              |
| ------------- | --------- | ---- | ----------------- |
| `y`           | `number`  | 是   | 农历年，1900-2100 |
| `m`           | `number`  | 是   | 农历月，1-12      |
| `d`           | `number`  | 是   | 农历日，1-30      |
| `isLeapMonth` | `boolean` | 否   | 是否闰月          |

闰月不存在、农历日期不存在、换算结果超过 2100-12-31 都会抛 `RangeError`。

## 返回值 LunarResult

| 字段                        | 类型                | 说明                                     |
| --------------------------- | ------------------- | ---------------------------------------- |
| `xiu`                       | `boolean`           | 是否在放假日列表；与周末无关             |
| `ban`                       | `boolean`           | 是否在补班日列表                         |
| `gljr`                      | `readonly string[]` | 公历节日，没有时是共享空数组             |
| `nljr`                      | `readonly string[]` | 农历节日，没有时是共享空数组             |
| `lYear` / `lMonth` / `lDay` | `number`            | 农历年 / 月 / 日                         |
| `isLeap`                    | `boolean`           | 是否闰月                                 |
| `lMonthCn` / `lDayCn`       | `string`            | 农历月 / 日中文，如 `"闰四月"`、`"廿一"` |
| `animal`                    | `string`            | 生肖，以农历年为准                       |
| `cYear` / `cMonth` / `cDay` | `number`            | 公历年 / 月 / 日                         |
| `gzYear`                    | `string`            | 干支年，以立春为界                       |
| `gzYearLunar`               | `string`            | 干支年，以正月初一为界                   |
| `gzMonth` / `gzDay`         | `string`            | 干支月（以节气为界）/ 干支日             |
| `gzHour`                    | `string[]`          | 当天十二个时辰的干支                     |
| `isToday`                   | `boolean`           | 是否今天（本地时区）                     |
| `nWeek`                     | `number`            | 星期 1-7，周日为 7                       |
| `dayOfWeek`                 | `number`            | 星期 0-6，周日为 0                       |
| `ncWeek`                    | `string`            | 星期中文，如 `"星期日"`                  |
| `term`                      | `string \| null`    | 节气名，非节气日为 `null`                |
| `astro`                     | `string`            | 星座，如 `"摩羯座"`                      |

```ts
const day = createCalendar().solarToLunar(2026, 10, 1);

day.lMonthCn; // "八月"
day.lDayCn; // "廿一"
day.gljr; // ["国庆节", ...]
day.xiu; // true
day.ban; // false
day.term; // 当天不是节气时为 null
```

## 节日与调休

### HolidayConfig

```ts
interface HolidayConfig {
  setFestival?: {
    /** 公历节日，key 为 MMDD */
    sFtv?: Record<string, string[]>;
    /** 农历节日，key 为 MMDD */
    lFtv?: Record<string, string[]>;
  };
  setRest?: {
    [year: string]: {
      /** 放假日期，MMDD */
      xiu?: string[];
      /** 补班日期，MMDD */
      ban?: string[];
    };
  };
}
```

```ts
const calendar = createCalendar({
  setFestival: {
    sFtv: { "0419": ["项目上线日"] },
    lFtv: { "0101": ["春节"] },
  },
  setRest: {
    2027: { xiu: ["0101", "0102"], ban: ["0104"] },
  },
});
```

- 默认与内置数据**合并去重**；
- `{ replace: true }` 丢弃内置数据；
- 不修改内置 JSON，也不修改入参对象；
- 年份范围 1900-2100，`MMDD` 必须是四位；
- 格式错误立即抛 `TypeError`，错误信息带字段路径。

### xiu / ban 的语义

`xiu` / `ban` **完全由配置决定，与周末无关**：

- 在 `xiu` 列表里：`day.xiu === true`；
- 在 `ban` 列表里：`day.ban === true`；
- 普通周末不会自动算作休息；判断周末请用 `day.dayOfWeek` 或 `day.nWeek`。

内置 2026 数据来自[国务院办公厅通知](https://www.gov.cn/zhengce/content/202511/content_7047090.htm)：

| 假期   | 放假        | 补班        |
| ------ | ----------- | ----------- |
| 元旦   | 1/1 - 1/3   | 1/4         |
| 春节   | 2/15 - 2/23 | 2/14、2/28  |
| 清明节 | 4/4 - 4/6   | -           |
| 劳动节 | 5/1 - 5/5   | 5/9         |
| 端午节 | 6/19 - 6/21 | -           |
| 中秋节 | 9/25 - 9/27 | -           |
| 国庆节 | 10/1 - 10/7 | 9/20、10/10 |

### getHolidays

```ts
const calendar = createCalendar({
  setRest: { 2027: { xiu: ["0101"] } },
});

const snapshot = calendar.getHolidays(); // 深拷贝
const copy = createCalendar(snapshot);
```

`HolidaySnapshot` 结构完整，可以直接传给 `createCalendar()`。

## 多套配置

没有全局状态，多套配置就是多个实例：

```ts
const mainland = createCalendar({
  setRest: { 2027: { xiu: ["0101", "0102"], ban: ["0104"] } },
});
const hongKong = createCalendar({
  setRest: { 2027: { xiu: ["0101"] } },
});

mainland.solarToLunar(2027, 1, 4).ban; // true
hongKong.solarToLunar(2027, 1, 4).ban; // false
```

## 工具函数

`utils` 是无状态具名导出，不读取实例配置：

```ts
import { utils } from "@sanguogege/calendar";

utils.lYearDays(2026); // 农历年天数
utils.leapMonth(2026); // 闰几月，0 表示不闰
utils.leapDays(2026); // 闰月天数
utils.lMonthDays(2026, 3); // 农历某月天数
utils.toChinaMonth(3); // "三月"
utils.toChinaDay(21); // "廿一"
utils.toChinaNum(3); // "三"
utils.solarDays(2026, 2); // 28
utils.solarFirstWeek(2026, 4); // 3（周日为 0）
utils.nthWeekdayOfMonth(2026, 5, 0, 2); // 10
utils.toAstro(4, 19); // "白羊座"
utils.getAnimal(2026); // "马"
utils.getTerm(2026, 3); // 4
utils.getSolarTerm(0); // "小寒"
utils.toGanZhi(40); // "甲辰"
utils.toGanZhiYear(2024); // "甲辰"
utils.toHourGanZhi(40); // ["甲子", "乙丑", ...]
```

## 错误与限制

| 异常         | 场景                                               |
| ------------ | -------------------------------------------------- |
| `RangeError` | 日期越界、日期不存在、闰月不匹配、工具函数参数越界 |
| `TypeError`  | `createCalendar` 的配置结构或类型不合法            |

```ts
try {
  createCalendar().solarToLunar(2024, 2, 30);
} catch (error) {
  console.error(error.message); // [calendar] solarToLunar(day) 必须在 1-29 之间，收到 30
}
```
