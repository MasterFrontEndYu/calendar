# calendar

零依赖的公历 / 农历换算库。完整 API 见 [calendar API](/api/calendar)。

```bash
bun add @sanguo-dev/calendar
```

```ts
import createCalendar, { utils } from "@sanguo-dev/calendar";

const calendar = createCalendar(); // 内置数据
const day = calendar.solarToLunar(2026, 10, 1);

day.lMonthCn; // "八月"
day.gljr; // ["国庆节", ...]
day.xiu; // true
```

## createCalendar

```ts
const calendar = createCalendar(config?, options?);
```

| 参数              | 类型            | 说明                     |
| ----------------- | --------------- | ------------------------ |
| `config`          | `HolidayConfig` | 节日 / 调休配置          |
| `options.replace` | `boolean`       | 为 `true` 时丢弃内置数据 |

- 不传参数时使用内置数据；
- 每次调用都是独立实例，没有全局状态；
- 配置在创建时校验、深拷贝并冻结；
- 多个实例互不影响，适合 SSR、并发和多套配置。

```ts
const company = createCalendar({
  setRest: {
    2027: { xiu: ["0101", "0102"], ban: ["0104"] },
  },
});

company.solarToLunar(2027, 1, 4).ban; // true
```

## 实例方法

| 方法                                  | 说明                                          |
| ------------------------------------- | --------------------------------------------- |
| `solarToLunar(y?, m?, d?)`            | 公历转农历；不传参数返回今天                  |
| `lunarToSolar(y, m, d, isLeapMonth?)` | 农历转公历                                    |
| `getHolidays()`                       | 当前配置的深拷贝，可再传给 `createCalendar()` |

完整接口见 [Calendar](/api/calendar/types/calendar)。

`solarToLunar` 参数：

| 参数 | 类型     | 必填 | 说明              |
| ---- | -------- | ---- | ----------------- |
| `y`  | `number` | 否   | 公历年，1900-2100 |
| `m`  | `number` | 否   | 公历月，1-12      |
| `d`  | `number` | 否   | 公历日            |

三个参数要么全部不传（取今天），要么全部传入。

`lunarToSolar` 参数：

| 参数          | 类型      | 必填 | 说明         |
| ------------- | --------- | ---- | ------------ |
| `y`           | `number`  | 是   | 农历年       |
| `m`           | `number`  | 是   | 农历月，1-12 |
| `d`           | `number`  | 是   | 农历日，1-30 |
| `isLeapMonth` | `boolean` | 否   | 是否闰月     |

## LunarResult

| 字段                        | 类型                | 说明                         |
| --------------------------- | ------------------- | ---------------------------- |
| `xiu`                       | `boolean`           | 是否在放假日列表；与周末无关 |
| `ban`                       | `boolean`           | 是否在补班日列表             |
| `gljr`                      | `readonly string[]` | 公历节日                     |
| `nljr`                      | `readonly string[]` | 农历节日                     |
| `lYear` / `lMonth` / `lDay` | `number`            | 农历年 / 月 / 日             |
| `isLeap`                    | `boolean`           | 是否闰月                     |
| `lMonthCn` / `lDayCn`       | `string`            | 农历月 / 日中文              |
| `animal`                    | `string`            | 生肖                         |
| `cYear` / `cMonth` / `cDay` | `number`            | 公历年 / 月 / 日             |
| `gzYear`                    | `string`            | 干支年（立春为界）           |
| `gzYearLunar`               | `string`            | 干支年（正月初一为界）       |
| `gzMonth` / `gzDay`         | `string`            | 干支月 / 日                  |
| `gzHour`                    | `string[]`          | 十二时辰干支                 |
| `isToday`                   | `boolean`           | 是否今天                     |
| `nWeek`                     | `number`            | 星期 1-7，周日为 7           |
| `dayOfWeek`                 | `number`            | 星期 0-6，周日为 0           |
| `ncWeek`                    | `string`            | 星期中文                     |
| `term`                      | `string \| null`    | 节气名                       |
| `astro`                     | `string`            | 星座                         |

完整字段说明见 [LunarResult](/api/calendar/types/lunar-result)。

## 节日与调休

```ts
interface HolidayConfig {
  setFestival?: {
    sFtv?: Record<string, string[]>; // 公历节日，MMDD
    lFtv?: Record<string, string[]>; // 农历节日，MMDD
  };
  setRest?: {
    [year: string]: {
      xiu?: string[]; // 放假 MMDD
      ban?: string[]; // 补班 MMDD
    };
  };
}
```

```ts
const calendar = createCalendar({
  setFestival: {
    sFtv: { "0419": ["项目上线日"] },
  },
  setRest: {
    2027: { xiu: ["0101", "0102"], ban: ["0104"] },
  },
});
```

- 默认与内置数据合并去重；
- `{ replace: true }` 丢弃内置数据；
- 年份 1900-2100，MMDD 必须四位；
- `xiu` / `ban` 只由配置决定，和周末无关；
- 判断周末用 `day.dayOfWeek` / `day.nWeek`。

完整字段见 [HolidayConfig](/api/calendar/types/holiday-config)。

内置数据来自国务院办公厅通知：[2026 年](https://www.gov.cn/zhengce/content/202511/content_7047090.htm)、[2027 年](https://www.gov.cn/zhengce/content/202611/content_7085101.htm)。

## getHolidays

const snapshot = calendar.getHolidays(); // 深拷贝

## utils

`utils` 是无状态具名导出：

```ts
import { utils } from "@sanguo-dev/calendar";

utils.lYearDays(2026);
utils.leapMonth(2026);
utils.leapDays(2026);
utils.lMonthDays(2026, 3);
utils.toChinaMonth(3); // "三月"
utils.toChinaDay(21); // "廿一"
utils.solarDays(2026, 2); // 28
utils.solarFirstWeek(2026, 4); // 3
utils.toAstro(4, 19); // "白羊座"
utils.getAnimal(2026); // "马"
utils.getTerm(2026, 3); // 4
utils.getSolarTerm(0); // "小寒"
utils.toGanZhi(40); // "甲辰"
utils.toGanZhiYear(2024); // "甲辰"
utils.toHourGanZhi(40); // ["甲子", "乙丑", ...]
```

## 错误

| 异常         | 场景                                  |
| ------------ | ------------------------------------- |
| `RangeError` | 日期越界、日期不存在、闰月不匹配      |
| `TypeError`  | `createCalendar` 配置结构或类型不合法 |

支持范围：`1900-01-31 ~ 2100-12-31`。
