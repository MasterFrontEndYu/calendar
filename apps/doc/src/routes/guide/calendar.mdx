# calendar 核心

`@sanguogege/calendar` 是零依赖的公历 / 农历换算库。

```bash
bun add @sanguogege/calendar
```

## 基本换算

```ts
import calendar from "@sanguogege/calendar";

const day = calendar.solarToLunar(2026, 10, 1);

day.lYear; // 农历年
day.lMonthCn; // "八月"
day.lDayCn; // "廿一"
day.term; // 节气名，非节气日为 null
day.gljr; // 公历节日
day.nljr; // 农历节日
day.gzYear; // 干支年（以立春为界）
day.astro; // 星座
```

农历转公历：

```ts
calendar.lunarToSolar(2024, 1, 1); // 2024-02-10
calendar.lunarToSolar(2020, 4, 1, true); // 2020-05-23（闰四月）
```

支持范围是 `1900-01-31 ~ 2100-12-31`。越界、日期不存在、只传部分参数都会抛 `RangeError`，不会静默回退到今天。

## 节日与调休

```ts
calendar.setHolidays({
  setFestival: {
    sFtv: { "0419": ["项目上线日"] },
    lFtv: { "0101": ["春节"] },
  },
  setRest: {
    2027: { xiu: ["0101", "0102"], ban: ["0104"] },
  },
});
```

- 默认与内置数据**合并去重**，重复调用继续叠加；
- `setHolidays(config, { replace: true })` 丢弃内置数据；
- `resetHolidays()` 恢复内置数据；
- `getHolidays()` 返回深拷贝，可以直接再传回去。

### xiu / ban 语义

`xiu` 和 `ban` **完全由 rest.json 决定，与周末无关**：

- `day.xiu === true`：在放假日列表里；
- `day.ban === true`：在调休补班列表里；
- 普通周末不会自动算作休息。

判断周末请用 `day.dayOfWeek`（0 为周日）或 `day.nWeek`（1-7，周日为 7）。

| 假期   | 放假        | 补班        |
| ------ | ----------- | ----------- |
| 元旦   | 1/1 - 1/3   | 1/4         |
| 春节   | 2/15 - 2/23 | 2/14、2/28  |
| 清明节 | 4/4 - 4/6   | -           |
| 劳动节 | 5/1 - 5/5   | 5/9         |
| 端午节 | 6/19 - 6/21 | -           |

数据来自[国务院办公厅关于 2026 年部分节假日安排的通知](https://www.gov.cn/zhengce/content/202511/content_7047090.htm)。2027 年通知发布后按年注入即可。

## 多套配置：createConverter

`setHolidays()` 是全局的；需要同一页面并排多套配置时，用 `createConverter()`：

```ts
const mainland = calendar.createConverter({
  setRest: { 2027: { xiu: ["0101", "0102"], ban: ["0104"] } },
});
const hongKong = calendar.createConverter({
  setRest: { 2027: { xiu: ["0101"] } },
});

mainland.solarToLunar(2027, 1, 4).ban; // true
hongKong.solarToLunar(2027, 1, 4).ban; // false
```

converter 的配置在创建时固定，之后与全局 `setHolidays()` 互不影响；`converter.getHolidays()` 可以取快照再复用。
