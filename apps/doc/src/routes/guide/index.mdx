# calendar

一套围绕中国日历的工具集，拆成“换算核心 / 纯公历 UI / 农历适配器”三层：

| 包                              | 作用                               | 运行时依赖                 |
| ------------------------------- | ---------------------------------- | -------------------------- |
| `@sanguogege/calendar`          | 公历 / 农历互转、节气、节日、调休  | 零依赖                     |
| `@sanguogege/calendar-ui`       | 纯公历 DOM 日历核心                | 零依赖                     |
| `@sanguogege/calendar-ui-lunar` | 把 `calendar` 接进 UI 的官方适配器 | `calendar` + `calendar-ui` |

## 安装

```bash
# 只要日期换算
bun add @sanguogege/calendar

# 纯公历 UI
bun add @sanguogege/calendar-ui

# 要农历 UI
bun add @sanguogege/calendar-ui @sanguogege/calendar-ui-lunar
```

## 按场景选择

| 场景                      | 入口                                                  |
| ------------------------- | ----------------------------------------------------- |
| 只需要日期数据            | `createCalendar()`                                    |
| 只需要公历日历组件        | `createCalendarUI()`                                  |
| 要农历、节气、节日、休班  | `createCalendarLunar()`                               |
| 有自己的历法 / 节假日接口 | 自己实现 `CalendarAdapter`，传给 `createCalendarUI()` |

## 设计原则

- **核心只做换算**：`calendar` 不碰 DOM，也不依赖框架。
- **没有全局状态**：节假日配置在 `createCalendar(config)` 创建时固定，多个实例互不影响。
- **UI 核心默认纯公历**：不装农历包、不 import 农历代码，默认 bundle 里没有农历数据。
- **公共适配器接口**：`CalendarAdapter` 是公开的，第三方可以接自己的历法或节假日源。

## 最小的三个例子

```ts
// 只换算
import createCalendar from "@sanguogege/calendar";

const calendar = createCalendar();
const day = calendar.solarToLunar(2026, 10, 1);
console.log(day.lMonthCn, day.lDayCn, day.term, day.gljr);
```

```ts
// 纯公历 UI
import { createCalendarUI } from "@sanguogege/calendar-ui";
import "@sanguogege/calendar-ui/style.css";

const instance = createCalendarUI(container, {
  onSelect: (day) => console.log(day.year, day.month, day.day, day.data),
});
```

```ts
// 农历 UI
import { createCalendarLunar } from "@sanguogege/calendar-ui-lunar";
import "@sanguogege/calendar-ui/style.css";

const instance = createCalendarLunar(container, {
  onSelect: (day) => console.log(day.subtitle, day.data?.lMonthCn),
});
```
