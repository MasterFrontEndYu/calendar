# 指南

围绕中国日历的三层工具：

| 包                              | 作用                               | 运行时依赖                 |
| ------------------------------- | ---------------------------------- | -------------------------- |
| `@sanguo-dev/calendar`          | 公历 / 农历换算、节气、节日、调休  | 零依赖                     |
| `@sanguo-dev/calendar-ui`       | 纯公历 DOM 日历核心                | 零依赖                     |
| `@sanguo-dev/calendar-ui-lunar` | 把 `calendar` 接入 UI 的官方适配器 | `calendar` + `calendar-ui` |

## 怎么选

- 只要日期数据：`@sanguo-dev/calendar`
- 只要公历日历：`@sanguo-dev/calendar-ui`
- 要农历、节气、节日、休班：`@sanguo-dev/calendar-ui-lunar`
- 有自己的历法 / 节假日接口：实现 `CalendarAdapter`，传给 `createCalendarUI`

## 三个包的文档

- [calendar](/guide/calendar)：换算、节气、节日、调休、`utils`。
- [calendar-ui](/guide/calendar-ui)：`createCalendarUI`、日期约束、范围、折叠、主题、动画、适配器。
- [calendar-ui-lunar](/guide/calendar-ui-lunar)：`createCalendarLunar`、`day.data`、`holidays`。

## 演示

- [calendar-ui 演示](/calendar-ui)：纯公历、多实例、范围、折叠、第三方适配器。
- [calendar-ui-lunar 演示](/calendar-ui-lunar)：内置农历数据、自定义 holidays。

`calendar` 不单独做演示页，示例直接写在对应指南里。
