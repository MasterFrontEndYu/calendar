# 第三方适配器

`calendar-ui` 的核心只负责公历网格、选中、键盘、头部和渲染；农历、节假日、月相之类的业务信息全部通过公开的 `CalendarAdapter` 注入。

这意味着你可以：

- 用官方 `@sanguogege/calendar-ui-lunar`；
- 自己实现一个适配器，接公司接口、数据库或其他历法；
- 不安装 `@sanguogege/calendar`，也不让农历数据进入默认 bundle。

## 接口

```ts
import type { CalendarAdapter, DayDecoration, MonthInput } from "@sanguogege/calendar-ui";

interface CalendarAdapter<TData = unknown> {
  readonly id: string;
  decorateMonth(input: MonthInput): ReadonlyArray<DayDecoration<TData> | null>;
}
```

| 成员            | 说明                                         |
| --------------- | -------------------------------------------- |
| `id`            | 适配器标识，用于调试和排查                   |
| `decorateMonth` | 每次渲染月视图调用一次，返回 42 格的装饰数组 |

`createCalendarUI` 的泛型会从 `adapter` 推导：

```ts
const adapter: CalendarAdapter<MyDay> = { ... };

const instance = createCalendarUI(container, {
  adapter,
  onSelect: (day) => {
    day.data; // MyDay | null
  },
});
```

## MonthInput

```ts
interface MonthInput {
  year: number;
  month: number;
  weekStartsOn: 0 | 1;
  today: Date;
  locale: CalendarLocale;
  days: readonly CalendarDate[];
}
```

| 字段           | 说明                             |
| -------------- | -------------------------------- |
| `year`         | 当前展示的年                     |
| `month`        | 当前展示的月，1-12               |
| `weekStartsOn` | 0 周日，1 周一                   |
| `today`        | 创建实例时捕获的今天             |
| `locale`       | 当前语言包                       |
| `days`         | 固定 42 个日期，包含上下月补位格 |

## CalendarDate

```ts
interface CalendarDate {
  year: number;
  month: number;
  day: number;
  date: Date;
  inCurrentMonth: boolean;
}
```

- `month` 是 1-12，不是 `Date` 的 0-11；
- `date` 是本地时区的 `Date`；
- `inCurrentMonth` 为 `false` 表示上一月/下一月的补位格。

适配器可以只装饰当前月的日期，也可以连补位格一起装饰：

```ts
decorateMonth({ days }) {
  return days.map((date) => (date.inCurrentMonth ? decorate(date) : null));
}
```

## DayDecoration

```ts
interface DayDecoration<TData = unknown> {
  subtitle?: string;
  badge?: CalendarBadge;
  data?: TData;
  ariaLabel?: string;
}
```

| 字段        | 说明                                               |
| ----------- | -------------------------------------------------- |
| `subtitle`  | 日期下方副标题，例如节气、节日、农历日             |
| `badge`     | 左上角标记                                         |
| `data`      | 透传给 `onSelect` 的数据，核心不解释               |
| `ariaLabel` | 覆盖默认无障碍名称；不传时由日期、标记、副标题拼接 |

返回数组必须和 `input.days` **按索引对齐**：

```ts
return input.days.map((date) => {
  if (!isHoliday(date)) return null;
  return {
    subtitle: "公司假日",
    badge: { text: "休", tone: "rest" },
    data: { date: date.date },
  };
});
```

没有装饰的位置返回 `null`。

## CalendarBadge 与 tone

```ts
interface CalendarBadge {
  text: string;
  tone?: string;
}
```

| 字段   | 说明                                                                  |
| ------ | --------------------------------------------------------------------- |
| `text` | 实际显示的文字，任意字符串，例如「休」「班」「假」                    |
| `tone` | 写到 `data-tone`，核心不解释；默认主题只内置 `rest` / `work` 两套颜色 |

默认主题：

```css
.cui__day-tag[data-tone="rest"] {
  color: var(--cui-rest);
}

.cui__day-tag[data-tone="work"] {
  color: var(--cui-accent);
}
```

自定义 tone：

```ts
badge: { text: "假", tone: "company" }
```

```css
.cui__day-tag[data-tone="company"] {
  color: #0a7;
}

.cui__day[data-tone="company"] .cui__day-sub {
  color: #0a7;
}
```

- `badge` 为 `null` 或 `undefined`：不显示标记；
- `tone` 不传：标记显示，但没有 `data-tone`；
- `rest` 还会让副标题变红（`.cui__day[data-tone="rest"] .cui__day-sub`）。

## 输出 CalendarDay

`decorateMonth` 的返回值会被组装成：

```ts
interface CalendarDay<TData = null> {
  year: number;
  month: number;
  day: number;
  date: Date;
  inCurrentMonth: boolean;
  isToday: boolean;
  isSelected: boolean;
  subtitle: string;
  badge: CalendarBadge | null;
  data: TData | null;
  ariaLabel: string;
}
```

`onSelect`、`select()`、自定义头部都能拿到这个对象。`data` 是适配器返回的原始引用，核心不做拷贝。

## 完整例子：xiu / ban 数据

下面这个第三方适配器完全不依赖 `@sanguogege/calendar`，数据写成和 `setRest` 相同的形状，`names` 提供副标题：

```ts
import { createCalendarUI } from "@sanguogege/calendar-ui";
import type { CalendarAdapter } from "@sanguogege/calendar-ui";

const COMPANY_REST = {
  2026: {
    xiu: ["0101", "0501", "0605", "1001"],
    ban: ["0613"],
    names: {
      "0101": "公司元旦",
      "0501": "公司劳动节",
      "0605": "六月公司日",
      "0613": "公司日补班",
      "1001": "公司国庆",
    },
  },
};

const pad = (value: number) => String(value).padStart(2, "0");

function getCompanyRest(date: Date) {
  const year = COMPANY_REST[String(date.getFullYear())];
  if (!year) return null;

  const mmdd = `${pad(date.getMonth() + 1)}${pad(date.getDate())}`;
  const subtitle = year.names?.[mmdd];

  if (year.ban?.includes(mmdd)) {
    return { type: "makeup" as const, subtitle: subtitle ?? "公司补班" };
  }
  if (year.xiu?.includes(mmdd)) {
    return { type: "holiday" as const, subtitle: subtitle ?? "公司假日" };
  }
  return null;
}

const adapter: CalendarAdapter<{ type: "holiday" | "makeup"; subtitle: string }> = {
  id: "company-holidays",
  decorateMonth({ days }) {
    return days.map((date) => {
      const rest = getCompanyRest(date.date);
      if (!rest) return null;

      return {
        subtitle: rest.subtitle,
        badge:
          rest.type === "holiday" ? { text: "休", tone: "rest" } : { text: "班", tone: "work" },
        data: rest,
      };
    });
  },
};

createCalendarUI(container, {
  initialDate: new Date(2026, 5, 1),
  adapter,
  onSelect: (day) => {
    console.log(day.subtitle); // "六月公司日" 等
    console.log(day.data?.type); // "holiday" | "makeup" | undefined
  },
});
```

这个例子的页面版本见[第三方适配器演示](/demo/custom)。

## 调用时机与缓存

`decorateMonth` 会在以下时机调用：

- 创建实例后的第一次渲染；
- 换月、`setMonth()`、前后翻月；
- 点击选中后刷新状态；
- `select()` 切换月份；
- 任何重新渲染。

它拿到的是同一个月份的 42 个日期，**适配器应该自己按 `year + month + weekStartsOn` 缓存重计算**。例如：

```ts
const cache = new Map<string, ReturnType<typeof decorateMonth>>();

decorateMonth(input) {
  const key = `${input.year}-${input.month}-${input.weekStartsOn}`;
  const cached = cache.get(key);
  if (cached) return cached;

  const result = input.days.map(decorate);
  cache.set(key, result);
  return result;
}
```

核心不缓存装饰结果，所以缓存失效完全由适配器自己控制。

## 约束与建议

### 同步、纯计算

`decorateMonth` 必须是同步的，不要在这里发请求或操作 DOM。需要远程数据时，先在外部加载好，再创建适配器或更新数据源。

### 不修改输入

不要修改 `input.days` 或 `CalendarDate` 对象；只返回新的装饰对象。

### 不支持的日期返回 null

范围外、查不到数据、接口异常都返回 `null`，不要把异常抛给核心：

```ts
try {
  return decorate(date);
} catch {
  return null;
}
```

### 数据按引用透传

`data` 不会被克隆。需要不可变数据时，在适配器里自己 freeze / copy。

### 性能

- 42 天一次批量计算，比逐日回调更适合缓存；
- 月份缓存 key 至少包含 `year`、`month`、`weekStartsOn`；
- 如果配置会变化（例如切换公司假日），清掉自己的缓存或重新创建适配器。

### SSR

适配器应该是纯函数，不访问 `window` / `document`。这样 `createCalendarUI` 在 SSR 时只渲染空壳，客户端 hydration 后再挂载。

### 打包边界

第三方适配器可以单独发包：

```text
@sanguogege/calendar-ui          核心，零依赖
@sanguogege/calendar-ui-lunar    官方农历适配器
your-calendar-ui-adapter         第三方适配器
```

核心不 import 适配器，只有真正使用该适配器的入口才会带上对应数据。
