# 演示

五个最小示例，分别对应几种接入方式：

- [纯公历 · 多实例](/demo/plain)：不安装农历包，同一页面创建多个日历。
- [范围选择](/demo/range)：单视图 / 双视图，点击起点和终点。
- [折叠](/demo/collapse)：底部箭头折叠，显示当前行 / 范围两行。
- [官方农历适配器](/demo/lunar)：使用 `@sanguogege/calendar-ui-lunar`，显示农历、节气、休班。
- [第三方适配器](/demo/custom)：不用官方农历包，自己实现节假日 / 调休方法并接到纯公历核心。
- [第三方适配器实现文档](/guide/adapter)：接口、属性、缓存和完整示例。

所有示例都只依赖公开 API，不修改 `calendar-ui` 源码。
