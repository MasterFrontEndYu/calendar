# 第三方适配器

这个示例完全不使用 `@sanguogege/calendar`。节假日和调休写成和 `setRest` 相同的数据形状，另外用 `names` 提供副标题：

```ts
{
  2026: {
    xiu: ["0101", "0501", "0605", "1001"],
    ban: ["0613"],
    names: { "0101": "公司元旦", "0605": "六月公司日" }
  }
}
```

再通过公开的 `CalendarAdapter` 接到纯公历核心上。

## 1. 节假日 / 调休数据

```ts
export interface CompanyRest {
  date: string;
  type: "holiday" | "makeup";
  subtitle: string;
}

export const COMPANY_REST = {
  2026: {
    xiu: ["0101", "0501", "0605", "1001"],
    ban: ["0613"],
    names: {
      "0101": "公司元旦",
      "0501": "公司劳动节",
      "0605": "六月公司日",
      "0613": "公司日补班",
      "1001": "公司国庆",
    },
  },
};

const pad = (value: number) => String(value).padStart(2, "0");

export function getCompanyRest(date: Date): CompanyRest | null {
  const year = COMPANY_REST[String(date.getFullYear())];
  if (!year) return null;

  const mmdd = `${pad(date.getMonth() + 1)}${pad(date.getDate())}`;
  const day = `${date.getFullYear()}-${pad(date.getMonth() + 1)}-${pad(date.getDate())}`;
  const subtitle = year.names?.[mmdd];

  if (year.ban?.includes(mmdd)) {
    return { date: day, type: "makeup", subtitle: subtitle ?? "公司补班" };
  }
  if (year.xiu?.includes(mmdd)) {
    return { date: day, type: "holiday", subtitle: subtitle ?? "公司假日" };
  }
  return null;
}
```

## 2. 映射成 CalendarAdapter

```ts
const adapter: CalendarAdapter<CompanyRest> = {
  id: "company-holidays",
  decorateMonth({ days }) {
    return days.map((date) => {
      const rest = getCompanyRest(date.date);
      if (!rest) return null;

      return {
        subtitle: rest.subtitle,
        badge:
          rest.type === "holiday" ? { text: "休", tone: "rest" } : { text: "班", tone: "work" },
        data: rest,
      };
    });
  },
};

const instance = createCalendarUI(host, {
  initialDate: new Date(2026, 5, 1),
  adapter,
});
```

核心只负责渲染 `subtitle` 和 `badge`；`xiu` / `ban` 的查询、副标题数据、缓存和接口请求都可以放在第三方适配器里。
