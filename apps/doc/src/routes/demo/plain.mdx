# 纯公历 · 多实例

同一个页面创建两个互不影响的实例。它们只使用 `@sanguogege/calendar-ui`，不加载农历数据。

## 实例 A：2026 年 10 月

<PlainCalendar year={2026} month={10} weekStartsOn={1} locale="zh-CN" />

```ts
const a = createCalendar(hostA, {
  initialDate: new Date(2026, 9, 1),
  weekStartsOn: 1,
  locale: "zh-CN",
  onSelect: (day) => console.log(day.year, day.month, day.day),
});
```

## 实例 B：2026 年 12 月

<PlainCalendar year={2026} month={12} weekStartsOn={0} locale="en-US" />

```ts
const b = createCalendar(hostB, {
  initialDate: new Date(2026, 11, 1),
  weekStartsOn: 0,
  locale: "en-US",
  onSelect: (day) => console.log(day.year, day.month, day.day),
});
```

两个实例的 `initialDate`、`weekStartsOn`、`locale` 完全独立；`destroy()` 也只影响自己。
