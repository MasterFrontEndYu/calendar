## 快速开始

```bash
bun add @sanguogege/calendar
bun add @sanguogege/calendar-ui @sanguogege/calendar-ui-lunar
```

- 只要日期换算：用 `@sanguogege/calendar`
- 只要公历 UI：用 `@sanguogege/calendar-ui`
- 要农历 UI：再加上 `@sanguogege/calendar-ui-lunar`
