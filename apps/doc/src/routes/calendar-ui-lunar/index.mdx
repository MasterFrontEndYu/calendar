# calendar-ui-lunar 演示

官方农历适配器。纯公历、多实例、范围、折叠等基础演示已经在 [calendar-ui](/calendar-ui) 展示，这里只展示农历相关部分。

## 内置数据

<LunarCalendar variant="builtin" />

```ts
import { createCalendarLunar } from "@sanguo-dev/calendar-ui-lunar";
import "@sanguo-dev/calendar-ui/style.css";

const instance = createCalendarLunar(container, {
  initialDate: "2026-10-01",
  onSelect: (day) => {
    day.subtitle; // "国庆节"
    day.badge; // { text: "休", tone: "rest" }
    day.data?.lMonthCn; // "八月"
  },
});
```

- 副标题优先级：节气 > 农历节日 > 公历节日 > 农历日；
- `xiu` 显示休，`ban` 显示班；
- `day.data` 是完整 `LunarResult`。

## 最小（min）

有副标题时整块从 194px 放大到 306px，格子 40px 正方形：

<LunarCalendar variant="builtin" size="min" />

```ts
createCalendarLunar(container, { size: "min" });
```

## 自定义样式

演示里的农历配色不是包自带的，而是示例给实例加了类、再覆写 CSS 变量（示例源码 `apps/doc/src/components/demo/lunar-theme.css`）：

```ts
instance.el.classList.add("cui--lunar-demo");
```

```css
.cui.cui--lunar-demo {
  --cui-bg: #fffbf9;
  --cui-accent: #c86055;
  --cui-rest: #c94f45;
}
```

核心只提供 `style.css` 的默认皮肤，配色按实例覆盖即可，light / dark / auto 都还生效。

[自定义 holidays](/calendar-ui-lunar/custom)

完整选项和 `day.data` 字段见 [calendar-ui-lunar 指南](/guide/calendar-ui-lunar)。
