# calendar-ui-lunar 演示

官方农历适配器。纯公历、多实例、范围、折叠等基础演示已经在 [calendar-ui](/calendar-ui) 展示，这里只展示农历相关部分。

## 内置数据

<CalendarUILunarIndex variant="builtin" />

```ts
import { createCalendarLunar } from "@sanguo-dev/calendar-ui-lunar";
import "@sanguo-dev/calendar-ui/style.css";

const instance = createCalendarLunar(container, {
  initialDate: "2026-10-01",
  onSelect: (day) => {
    day.subtitle; // "国庆节"
    day.badge; // { text: "休", tone: "rest" }
    day.data?.lMonthCn; // "八月"
  },
});
```

- 副标题优先级：节气 > 农历节日 > 公历节日 > 农历日；
- `xiu` 显示休，`ban` 显示班；
- `day.data` 是完整 `LunarResult`。

## 最小（min）

有副标题时整块从 194px 放大到 306px，格子 40px 正方形：

<CalendarUILunarIndex variant="builtin" size="min" />

```ts
createCalendarLunar(container, { size: "min" });
```

## 铺满容器（fill）

宽度铺满容器，格子是 16:10 长方形：数字和副标题居中堆叠，休 / 班角标留在左上角。

<CalendarUILunarIndex variant="builtin" size="fill" />

```ts
createCalendarLunar(container, { size: "fill" });
```

## 自定义样式

下面只保留这一个实例使用自定义样式，其他演示都使用默认皮肤。做法是给实例根节点加类，再覆写 CSS 变量（示例源码 `apps/doc/src/components/demo/calendar-ui-lunar-theme.css`）：

<CalendarUILunarIndex variant="builtin" styled />

```ts
instance.el.classList.add("cui--lunar-demo");
```

```css
/*
 * 演示用：只在某个农历实例上覆盖一套「农历喜庆红」配色。
 *
 * 核心包只提供默认皮肤，这里演示实例级自定义样式的做法：
 *   instance.el.classList.add("cui--lunar-demo");
 *
 * 颜色全部是 CSS 变量，覆写后 light / dark / auto 仍然生效。
 */
.cui.cui--lunar-demo {
  --cui-bg: #fffbf9;
  --cui-fg: #43302e;
  --cui-muted: #a68c87;
  --cui-border: #f2ded9;
  --cui-accent: #c86055;
  --cui-accent-fg: #fffdfc;
  --cui-rest: #c94f45;
  --cui-hover: #fbefec;
  --cui-radius: 12px;
}

/* 显式深色，或外层 data-theme="dark" 时跟随 */
.cui.cui--lunar-demo[data-theme="dark"],
[data-theme="dark"] .cui.cui--lunar-demo[data-theme="auto"] {
  --cui-bg: #1b1413;
  --cui-fg: #f3e6e3;
  --cui-muted: #a98f8a;
  --cui-border: #3a2b29;
  --cui-accent: #e28277;
  --cui-accent-fg: #2a1210;
  --cui-rest: #ef8d83;
  --cui-hover: #2a1e1d;

  color-scheme: dark;
}

/* auto 跟随系统 */
@media (prefers-color-scheme: dark) {
  .cui.cui--lunar-demo[data-theme="auto"] {
    --cui-bg: #1b1413;
    --cui-fg: #f3e6e3;
    --cui-muted: #a98f8a;
    --cui-border: #3a2b29;
    --cui-accent: #e28277;
    --cui-accent-fg: #2a1210;
    --cui-rest: #ef8d83;
    --cui-hover: #2a1e1d;

    color-scheme: dark;
  }

  /* 外层明确 light 时，系统深色不覆盖 */
  [data-theme="light"] .cui.cui--lunar-demo[data-theme="auto"] {
    --cui-bg: #fffbf9;
    --cui-fg: #43302e;
    --cui-muted: #a68c87;
    --cui-border: #f2ded9;
    --cui-accent: #c86055;
    --cui-accent-fg: #fffdfc;
    --cui-rest: #c94f45;
    --cui-hover: #fbefec;

    color-scheme: light;
  }
}
```

核心只提供 `style.css` 的默认皮肤，配色按实例覆盖即可，light / dark / auto 都还生效。
