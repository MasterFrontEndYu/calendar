# 自定义 holidays

每个实例可以带自己的节日 / 调休配置，互不影响。

<CalendarUILunarCustom />

```ts
const instance = createCalendarLunar(container, {
  initialDate: "2026-01-01",
  holidays: {
    setFestival: { sFtv: { "0105": ["公司年会"] } },
    setRest: { 2026: { xiu: ["0105"], ban: ["0106"] } },
  },
});
```

- `holidays` 在创建时校验并固定；
- `replaceHolidays: true` 时忽略内置数据；
- 配置相同的对象可以共享月份缓存。

完整 `HolidayConfig` 见 [HolidayConfig](/api/calendar/types/holiday-config)，实例选项见 [createCalendarLunar](/api/calendar-ui-lunar/createCalendarLunar)。
