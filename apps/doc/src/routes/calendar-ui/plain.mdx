# 基础与多实例

同一个页面可以创建多个互不影响的日历实例。

头部的年份和月份是两个按钮：点哪个就从下方弹出哪个面板，选完立即关闭。

## 默认实例

<CalendarUIPlain year={2026} month={10} weekStartsOn={1} locale="zh-CN" />

```ts
const a = createCalendarUI(hostA, {
  initialDate: "2026-10-01",
  weekStartsOn: 1,
  locale: "zh-CN",
  onSelect: (day) => console.log(day.year, day.month, day.day),
});
```

## 深色实例

<CalendarUIPlain year={2026} month={12} weekStartsOn={0} locale="en-US" theme="dark" />

```ts
const b = createCalendarUI(hostB, {
  initialDate: "2026-12-01",
  weekStartsOn: 0,
  locale: "en-US",
  theme: "dark",
  onSelect: (day) => console.log(day.year, day.month, day.day),
});
```

两个实例的初始月份、周起始、语言、主题完全独立；`destroy()` 也只影响自己。

## 最小（min）

24px 正方形格子，没有副标题时整块只有 194px 宽：

<CalendarUIPlain year={2026} month={10} size="min" />

```ts
const c = createCalendarUI(hostC, {
  initialDate: "2026-10-01",
  size: "min",
});
```

## 铺满容器（fill）

容器有多宽就铺多宽，格子是 16:10 长方形，高度比正方形矮，最小 48px 宽：

<CalendarUIPlain year={2026} month={10} size="fill" />

```ts
const d = createCalendarUI(hostD, {
  initialDate: "2026-10-01",
  size: "fill",
});
```

完整选项见 [CalendarOptions](/api/calendar-ui/CalendarOptions)。
