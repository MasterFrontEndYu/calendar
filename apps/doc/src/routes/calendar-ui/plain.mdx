# 基础与多实例

同一个页面可以创建多个互不影响的日历实例。

## 默认实例

<PlainCalendar year={2026} month={10} weekStartsOn={1} locale="zh-CN" />

```ts
const a = createCalendarUI(hostA, {
  initialDate: "2026-10-01",
  weekStartsOn: 1,
  locale: "zh-CN",
  onSelect: (day) => console.log(day.year, day.month, day.day),
});
```

## 深色实例

<PlainCalendar year={2026} month={12} weekStartsOn={0} locale="en-US" theme="dark" />

```ts
const b = createCalendarUI(hostB, {
  initialDate: "2026-12-01",
  weekStartsOn: 0,
  locale: "en-US",
  theme: "dark",
  onSelect: (day) => console.log(day.year, day.month, day.day),
});
```

两个实例的初始月份、周起始、语言、主题完全独立；`destroy()` 也只影响自己。

完整选项见 [calendar-ui 指南](/guide/calendar-ui)。
