# 日期格 popup

数据在 `createCalendarUI` 之前准备好，直接传给 `popup.render(day)`。库在创建 / 重绘时调用它：

- 返回非空数组 → 这一天有 popup，日期格右上角自动出现绿点；
- 返回空数组 → 这一天没有 popup，也没有绿点；
- 打开弹层时复用创建时渲染好的内容，自动补一行「日期 · 条数」头部。

<CalendarUIPopup />

## 交互约定

- **绿点由库内部算**：`render(day).length > 0` 才显示；
- **没有关闭按钮**：点击其他日期、点击空白处、按 `Esc`、换月、滚动或缩放页面都会关闭；
- **数据必须在创建前准备好**：`render` 是同步纯函数，库不负责请求数据；
- **点击触发**用 `role="dialog"`，点击日期时仍然会选中日期；
- **悬停触发**用 `role="tooltip"`，只适合只读内容；移动端没有 hover，交互示例请用 `click` 或 `auto`；
- 头部「日期 · 条数」里的条数就是 `render` 返回数组的长度，所以一条数据对应数组里的一项。

## 示例一：系统 UI（点击触发）

这个示例只 import `@sanguo-dev/calendar-ui/style.css`，不写任何 popup 皮肤。`render` 返回字符串数组：

- `.cui__popup` 默认卡片：背景、边框、圆角、阴影、内边距；
- `.cui__popup-head`：自动显示「10 月 1 日 · 2 条」；
- `.cui__popup-item` 里的 `.cui__popup-title`：每个字符串的默认 12px 排版；
- `.cui__popup-body` / `.cui__popup-item`：内容容器和每一层之间的分隔线。

```tsx
import { createSignal, onSettled } from "solid-js";
import { createCalendarUI } from "@sanguo-dev/calendar-ui";
import type { CalendarDate } from "@sanguo-dev/calendar-ui";
import "@sanguo-dev/calendar-ui/style.css";
import "./calendar-ui-popup.css";
import "./demo.css";

interface PopupEntry {
  title: string;
  detail: string;
  time: string;
}

/** 演示数据 */
const POPUPS: Record<string, readonly PopupEntry[]> = {
  "2026-10-1": [
    { title: "国庆节", detail: "10 月 1 日 - 7 日放假", time: "全天" },
    { title: "升旗仪式", detail: "广场集合，提前 10 分钟到场", time: "10:00" },
  ],
  "2026-10-8": [{ title: "寒露", detail: "早晚温差大，记得添衣", time: "节气" }],
  "2026-10-18": [{ title: "重阳节", detail: "登高、敬老", time: "农历九月初九" }],
  "2026-10-23": [{ title: "霜降", detail: "秋季最后一个节气", time: "节气" }],
  "2026-10-31": [{ title: "万圣夜", detail: "18:00 公司活动", time: "18:00" }],
};

/** 日期 -> 数据 key */
const keyOf = function (day: CalendarDate): string {
  return `${day.year}-${day.month}-${day.day}`;
};

/** 取这一天的数据 */
const entriesOf = function (day: CalendarDate): readonly PopupEntry[] {
  return POPUPS[keyOf(day)] ?? [];
};

/** 系统 UI：一条数据返回一个字符串，交给库的默认弹层样式 */
const render = function (day: CalendarDate): string[] {
  return entriesOf(day).map((entry) => `${entry.time} · ${entry.title}：${entry.detail}`);
};

export default function CalendarUIPopupDefault() {
  let host: HTMLDivElement | undefined;
  const [picked, setPicked] = createSignal("未选择");

  onSettled(() => {
    if (!host) return;

    const instance = createCalendarUI(host, {
      initialDate: "2026-10-01",
      onSelect: (day) => setPicked(keyOf(day)),
      popup: {
        trigger: "click",
        ariaLabel: "日期详情",
        render,
      },
    });

    return () => instance.destroy();
  });

  return (
    <section class="demo-popup-panel">
      <header class="demo-popup-panel-head">
        <h3>系统 UI · 点击触发</h3>
        <p>
          <code>render</code> 返回字符串数组，直接用库的默认弹层样式；绿点和「日期 ·
          条数」由库内部算。
        </p>
      </header>
      <div ref={(el) => (host = el)} />
      <p class="demo-result">已选中：{picked()}</p>
    </section>
  );
}
```

## 示例二：自定义 UI（悬停触发）

这个示例用另一份数据、另一个 `render`：返回 Node 数组，外层用自己的类名，内部复用库的 title / time / detail 结构。库仍然自动加「日期 · 条数」头部，但容器外观由下面的 CSS 改掉。

```tsx
import { createSignal, onSettled } from "solid-js";
import { createCalendarUI } from "@sanguo-dev/calendar-ui";
import type { CalendarDate } from "@sanguo-dev/calendar-ui";
import "@sanguo-dev/calendar-ui/style.css";
import "./calendar-ui-popup.css";
import "./calendar-ui-popup-custom.css";
import "./demo.css";

interface PopupEntry {
  title: string;
  detail: string;
  time: string;
}

/** 演示数据 */
const POPUPS: Record<string, readonly PopupEntry[]> = {
  "2026-10-1": [
    { title: "国庆节", detail: "10 月 1 日 - 7 日放假", time: "全天" },
    { title: "升旗仪式", detail: "广场集合，提前 10 分钟到场", time: "10:00" },
  ],
  "2026-10-8": [{ title: "寒露", detail: "早晚温差大，记得添衣", time: "节气" }],
  "2026-10-18": [{ title: "重阳节", detail: "登高、敬老", time: "农历九月初九" }],
  "2026-10-23": [{ title: "霜降", detail: "秋季最后一个节气", time: "节气" }],
  "2026-10-31": [{ title: "万圣夜", detail: "18:00 公司活动", time: "18:00" }],
};

/** 日期 -> 数据 key */
const keyOf = function (day: CalendarDate): string {
  return `${day.year}-${day.month}-${day.day}`;
};

/** 取这一天的数据 */
const entriesOf = function (day: CalendarDate): readonly PopupEntry[] {
  return POPUPS[keyOf(day)] ?? [];
};

/** 自定义 UI：一条数据返回一个带自己类名的 Node */
const createRow = function (entry: PopupEntry): HTMLElement {
  const row = document.createElement("article");
  row.className = "demo-popup-row";

  const title = document.createElement("div");
  title.className = "demo-popup-title";

  const time = document.createElement("span");
  time.className = "demo-popup-time";
  time.textContent = entry.time;

  const name = document.createElement("strong");
  name.textContent = entry.title;

  title.append(time, name);

  const detail = document.createElement("span");
  detail.className = "demo-popup-detail";
  detail.textContent = entry.detail;

  row.append(title, detail);
  return row;
};

const render = function (day: CalendarDate): HTMLElement[] {
  return entriesOf(day).map((entry) => createRow(entry));
};

export default function CalendarUIPopupCustom() {
  let host: HTMLDivElement | undefined;
  const [picked, setPicked] = createSignal("未选择");

  onSettled(() => {
    if (!host) return;

    const instance = createCalendarUI(host, {
      initialDate: "2026-10-01",
      onSelect: (day) => setPicked(keyOf(day)),
      popup: {
        trigger: "hover",
        ariaLabel: "日期详情",
        render,
      },
    });

    // 自定义示例：只在这里给日历根节点加类，CSS 由使用方自己写
    instance.el.classList.add("demo-calendar--custom");

    return () => instance.destroy();
  });

  return (
    <section class="demo-popup-panel demo-popup-panel--custom">
      <header class="demo-popup-panel-head">
        <h3>自定义 UI · 悬停触发</h3>
        <p>
          <code>render</code> 返回 Node 数组，每个 Node 带自己的类名，样式完全由使用方 CSS 决定。
        </p>
      </header>
      <div ref={(el) => (host = el)} />
      <p class="demo-result">已选中：{picked()}</p>
    </section>
  );
}
```

## 渲染规则

```ts
render(day: CalendarDate): readonly DayPopupItem[];
type DayPopupItem = string | Node;
```

- `render` 在创建 / 重绘时调用，返回结果会缓存，打开 popup 时不再调用；
- 数组长度就是头部显示的「几条」，一条数据对应一项；
- `string[]`、`Node[]` 或两者混合都支持；字符串会被放进 `.cui__popup-item > .cui__popup-title`，用 `textContent` 挂载，**不会解析 HTML**；
- Node 由库包进 `.cui__popup-item`，内部结构和类名完全由使用方决定；
- Node 直接 append，所以 Node 要在 `render` 里新建，不要跨日期复用同一个实例；
- 返回空数组 → 没有绿点，点击也不会打开；
- `render` 必须是同步纯函数，不能返回 Promise，也不要在里面发请求；数据请在 `createCalendarUI` 之前准备好。

## 触发方式

```ts
trigger: "click" | "hover" | "focus" | "auto";
```

- 默认 `"click"`，点击日期时同时选中日期；
- `"hover"` 只适合桌面端只读内容，移动端没有 hover；
- `"auto"` 在支持 hover 的设备用 hover，触摸设备用 click；
- `"focus"` 用于键盘聚焦；
- 默认 click 用 `role="dialog"`，其余用 `role="tooltip"`，可用 `role` 覆盖。

## 移动端

- 用 `click` 或 `auto`，不要用 `hover`；
- 窄屏可以用 `placement: "center"` 做居中弹层，或用自己的 CSS 改成底部 sheet；
- 库已经给了 `max-height: 70vh; overflow: auto`，内容多时可以直接滚动；
- 关闭由点击外部 / `Esc` 负责，不需要额外放关闭按钮。

完整字段见 [CalendarOptions](/api/calendar-ui/CalendarOptions#calendarpopupoptions)。
