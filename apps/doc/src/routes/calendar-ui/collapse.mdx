# 折叠

配置 `animation.collapse` 后，底部出现单状态上下箭头；默认展开。折叠/展开由底部箭头控制，不提供额外的实例方法。

## 单选

<CalendarUICollapse mode="single" />

```ts
const instance = createCalendarUI(host, {
  initialDate: "2026-10-15",
  animation: { collapse: {} },
});
```

点击其他日期，折叠行会跟随；底部箭头切换展开/折叠。

## 范围

<CalendarUICollapse mode="range" />

```ts
const instance = createCalendarUI(host, {
  mode: "range",
  initialDate: "2026-10-15",
  animation: { collapse: {} },
});
```

范围折叠时同时显示起点行和终点行；两个端点同一周时只显示一行。

## 默认折叠

```ts
createCalendarUI(host, {
  animation: {
    collapse: { defaultCollapsed: true },
  },
});
```

- `collapse: {}`：开启折叠，默认 200ms / `ease`，初始展开；
- `collapse.defaultCollapsed: true`：初始折叠；
- `collapse.duration: 0`：保留箭头，但折叠/展开不做过渡。

完整折叠字段见 [CalendarAnimationOptions](/api/calendar-ui/types/calendar-animation)。
