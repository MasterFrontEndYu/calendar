# 翻月动画

翻月动画默认关闭：不配置 `animation.slide` 时，切换月份是直接换内容。配置 `slide: {}` 即开启，默认 220ms / `ease`。

## 开启滑动

<CalendarUITransition />

```ts
const instance = createCalendarUI(host, {
  initialDate: "2026-10-15",
  animation: {
    slide: {}, // 等价于 { duration: 220, easing: "ease" }
  },
  onMonthChange: (year, month) => {
    console.log(year, month);
  },
});
```

## 慢速 + linear

<CalendarUITransition duration={600} easing="linear" />

```ts
const instance = createCalendarUI(host, {
  initialDate: "2026-10-15",
  animation: {
    slide: { duration: 600, easing: "linear" },
  },
});
```

## 关闭动画

```ts
createCalendarUI(host, {
  // 不传 animation.slide 即可；animation: {} 也一样
});
```

- `slide: {}` 开启滑动，缺省 220ms / `ease`；
- 不配置 `animation.slide` 时翻月直接切换；
- `prefers-reduced-motion: reduce` 下自动关闭；
- 时长、缓动也可以通过 `.cui` 的 `--cui-month-duration`、`--cui-month-easing` 覆盖。
